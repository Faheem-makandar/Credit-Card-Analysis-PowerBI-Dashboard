# Credit-Card-Analysis-PowerBI-Dashboard

💳 Credit Card Transaction Dashboard
1. Credit Card Analysis

Credit Card Analytics: Transaction & Revenue Performance Dashboard
An interactive Power BI dashboard designed to analyze credit card transactions, customer spending behavior, and revenue trends—helping identify profitable segments and optimize business strategies.

2. Short Description / Purpose

This Power BI dashboard visualizes large-scale credit card transaction data to uncover key insights related to revenue generation, customer segmentation, and interest earned.
It helps financial institutions track customer performance, card type usage, and income group behavior for strategic decision-making.

3. Tech Stack

📊 Power BI Desktop – For dashboard development and visualization.

🔄 Power Query – Used for data cleaning, transformation, and shaping.

🧮 DAX (Data Analysis Expressions) – Created KPIs such as Revenue, Transactions, and Interest Earned.

🔗 Data Modeling – Established relationships between customer and transaction tables.

📁 CSV/Excel Data Source – Raw data imported for analysis.

4. Key Features

KPIs for Revenue, Total Transactions, Interest Earned, and Transaction Count.

Quarterly revenue trend analysis using line and bar combination charts.

Interactive filters for Card Category, Gender, Income Group, and City.

Revenue by Expenditure Type, Chip Usage, and Customer Segment.

Customer segmentation by Education Level, Occupation, and Loan Type.

5. Insights & Observations

💰 Revenue: Highest revenue generated from Silver cards, followed by Blue cards.

👥 Customer Behavior: Businessmen and self-employed individuals contribute most to credit card revenue.

🏦 Spending Pattern: Majority of spending occurs via swipe transactions (≈35M), indicating offline preference.

🎓 Education Level: Graduates dominate the customer base, highlighting strong engagement among educated users.

🕓 Quarterly Trend: Revenue peaks during Q3, possibly due to festive or seasonal shopping periods.

6. Workflow / Process

Data Import: Loaded customer and transaction datasets into Power BI.

Data Cleaning: Removed null values and formatted numeric fields.

Data Modeling: Built relationships between customer and transaction tables.
